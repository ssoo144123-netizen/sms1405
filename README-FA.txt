SmsPro v3 - راهنمای نصب و استفاده

۱. ساخت APK در GitHub
   - محتوای این پوشه را در یک repository جدید آپلود کنید.
   - فایل .github/workflows/main.yml باید محتوا داشته باشد.
   - تب Actions ← آخرین اجرا ← Artifacts ← smspro-apk را دانلود کنید.

۲. نصب و اولین اجرا
   - نسخه‌های قدیمی را حذف کنید، بعد app-debug.apk را نصب کنید.
   - دسترسی‌های پیامک، مخاطبین و اعلان را بدهید.
   - وقتی پیام پیامک‌رسان پیش‌فرض آمد، «تنظیم» را بزنید و SmsPro را انتخاب کنید.

۳. امکانات
   - لیست گفتگوها با نام مخاطب از دفترچه تلفن
   - جستجو در لیست و داخل گفتگو
   - فیلتر همه / خوانده‌نشده / خوانده‌شده
   - انتخاب چندتایی، حذف، خوانده/نخوانده، ذخیره در Download
   - نگه‌داشتن روی گفتگو: باز کردن، تماس، بلاک، حذف، خوانده/نخوانده، ذخیره
   - داخل گفتگو: ارسال، تماس، بلاک، انتخاب و حذف پیام‌ها
   - نگه‌داشتن روی پیام: کپی، فوروارد، حذف، خوانده، جزئیات
   - بلاک‌لیست در تنظیمات (افزودن و حذف شماره)
   - ۱۲ رنگ اصلی و حالت تیره در تنظیمات

۴. محدودیت‌ها
   - پیام‌های MMS (تصویری/صوتی)، RCS، پیام گروهی و چند سیم‌کارته پشتیبانی نمی‌شوند.
   - برای برگشت به پیامک‌رسان قبلی، در تنظیمات گوشی برنامه پیش‌فرض پیامک را عوض کنید.
